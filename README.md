A deadpan one-star review of sleep, filed in earnest against a thing that cannot be fixed.

## Entry

> Sleep: advertised 8 hours, delivered 4. Woke up more tired than before. Would not recommend. One star.

## How it works

`main.py` writes the review — one line, 102 characters — to `/output/entry.txt`. Pure Python standard library, no network, no input files.

Run it:

```sh
python3 main.py
```
